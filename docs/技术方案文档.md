# WMS IES Core 技术方案文档

## 1. 项目概述

### 1.1 项目简介
WMS IES Core 是一个基于 Spring Boot 的在线考试系统核心项目，提供完整的考试管理、试题管理、用户管理和数据分析功能。系统采用前后端分离架构，后端提供 RESTful API 接口，支持多种数据库操作和数据迁移功能。

### 1.2 技术栈
- **后端框架**: Spring Boot 2.7.0
- **数据库**: MySQL
- **ORM框架**: MyBatis
- **API文档**: SpringDoc OpenAPI 3.0
- **构建工具**: Maven
- **Java版本**: JDK 1.8
- **其他技术**: Lombok, SLF4J, Logback, Redis, FastJSON

## 2. 系统架构

### 2.1 整体架构
系统采用经典的三层架构设计：
- **表现层(Controller)**: 处理HTTP请求，参数验证，调用服务层
- **业务层(Service)**: 实现业务逻辑，事务管理
- **数据访问层(Mapper/DAO)**: 数据库操作，SQL映射

### 2.2 模块划分
系统按功能划分为以下核心模块：
- 用户管理模块
- 试题管理模块
- 试卷管理模块
- 考试管理模块
- 数据分析模块
- 数据迁移模块
- 通用CRUD模块

## 4. 功能模块详解

### 4.1 用户管理模块

#### 4.1.1 功能概述
用户管理模块负责系统用户的增删改查、权限管理和用户分组管理。

#### 4.1.2 核心接口
- **用户CRUD操作**: `/api/user/*`
  - 添加用户: `POST /api/user/add`
  - 删除用户: `POST /api/user/delete`
  - 更新用户: `POST /api/user/update`
  - 获取用户: `POST /api/user/getById`
  - 获取用户列表: `POST /api/user/list`
  - 设置管理员权限: `POST /api/user/setAdmin`
  - 设置用户禁用状态: `POST /api/user/setDisabled`

- **用户分组管理**: `/api/userGroup/*`
  - 创建分组: `POST /api/userGroup/create`
  - 更新分组: `POST /api/userGroup/update`
  - 删除分组: `POST /api/userGroup/delete`
  - 获取分组详情: `POST /api/userGroup/getById`
  - 获取所有分组: `POST /api/userGroup/list`
  - 添加用户到分组: `POST /api/userGroup/addUserToGroup`
  - 从分组中移除用户: `POST /api/userGroup/removeUserFromGroup`
  - 获取分组成员: `POST /api/userGroup/getGroupMembers`
  - 获取用户所属分组: `POST /api/userGroup/getUserGroups`

#### 4.1.3 实现类
- **Controller**: `UserController.java`, `EtUserGroupController.java`
- **Service**: `UserService.java`, `EtUserGroupService.java`
- **Model**: `EtUser.java`, `EtUserGroup.java`, `EtUserGroupMember.java`

### 4.2 试题管理模块

#### 4.2.1 功能概述
试题管理模块负责试题的增删改查、分类管理、难度管理和知识点关联。

#### 4.2.2 核心接口
- **试题CRUD操作**: `/api/question/*`
  - 添加试题: `POST /api/question/add`
  - 编辑试题: `POST /api/question/update`
  - 删除试题: `POST /api/question/delete`
  - 获取试题详情: `POST /api/question/getById`
  - 按分组获取试题: `POST /api/question/getByGroupId`
  - 按题型获取试题: `POST /api/question/getByType`
  - 获取所有试题: `POST /api/question/list`
  - 搜索试题: `POST /api/question/search`
  - 获取可见试题: `POST /api/question/getVisible`
  - 按难度获取试题: `POST /api/question/getByDifficulty`
  - 按创建人获取试题: `POST /api/question/getByCreator`

- **管理员试题管理**: `/admin/question/*`
  - 查询试题列表: `POST /admin/question/list`
  - 获取所有题库: `POST /admin/question/fields`
  - 获取所有知识点: `POST /admin/question/knowledge-points`
  - 查询试题详情: `POST /admin/question/detail`
  - 保存试题: `POST /admin/question/save`
  - 批量删除试题: `POST /admin/question/batch-delete`

- **题库管理**: `/admin/question/field/*`
  - 保存题库: `POST /admin/question/field/save`

- **知识点管理**: `/admin/question/knowledge-point/*`
  - 保存知识点: `POST /admin/question/knowledge-point/save`

#### 4.2.3 实现类
- **Controller**: `EtQuestionController.java`, `AdminQuestionController.java`
- **Service**: `EtQuestionService.java`, `AdminQuestionService.java`, `AdminFieldService.java`, `AdminKnowledgePointService.java`
- **Model**: `EtQuestion.java`, `EtField.java`, `EtKnowledgePoint.java`, `EtQuestion2Point.java`

## 5. 通用组件

### 5.1 统一响应结果
系统使用`ResponseResult<T>`类作为统一响应结果封装，包含响应码、响应消息、响应数据和时间戳。

```java
@Data
public class ResponseResult<T> {
    private Integer code;
    private String message;
    private T data;
    private Long timestamp;
    
    // 静态方法
    public static <T> ResponseResult<T> success(T data);
    public static <T> ResponseResult<T> fail(String message);
    // ...其他方法
}
```

### 5.2 全局异常处理
系统使用`GlobalExceptionHandler`类进行全局异常处理，统一处理业务异常、参数验证异常、HTTP异常等。

```java
@RestControllerAdvice
public class GlobalExceptionHandler {
    @ExceptionHandler(BusinessException.class)
    public ResponseResult<String> handleBusinessException(BusinessException e);
    
    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseResult<String> handleMethodArgumentNotValidException(MethodArgumentNotValidException e);
    // ...其他异常处理方法
}
```
