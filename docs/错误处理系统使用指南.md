# 错误处理系统使用指南

## 1. 概述

本文档详细介绍了WMS-IES-CORE项目错误处理系统的使用方法，包括异常定义、异常处理、错误码使用、监控告警等功能。

## 2. 核心组件

### 2.1 错误码体系

系统采用层次化的错误码分类体系：

- **业务错误** (1000-1999): 用户、试卷、题目、考试等业务相关错误
- **参数验证错误** (2000-2999): 参数格式、类型、范围等验证错误
- **数据操作错误** (3000-3999): 数据库操作相关错误
- **文件操作错误** (4000-4999): 文件上传、下载、格式等错误
- **系统错误** (5000-5999): 系统内部、数据库、配置等错误
- **网络错误** (6000-6999): 网络连接、超时等错误

### 2.2 核心类说明

#### 2.2.1 ResponseCode (错误码枚举)

```java
// 使用示例
throw new BusinessException(ResponseCode.USER_NOT_FOUND);
throw new BusinessException(ResponseCode.USER_NOT_FOUND, "用户ID: " + userId);
```

#### 2.2.2 ErrorCategory (错误分类)

```java
// 获取错误分类
ErrorCategory category = ErrorCategory.fromCode(1001);
String description = category.getDescription(); // "业务错误"
```

#### 2.2.3 ErrorDetail (错误详情)

```java
// 创建错误详情
ErrorDetail errorDetail = ErrorDetail.of(ResponseCode.USER_NOT_FOUND, request);

// 错误详情包含以下字段：
// - code: 错误码
// - message: 错误消息
// - type: 错误类型
// - timestamp: 时间戳
// - path: 请求路径
// - suggestion: 解决方案建议
// - requestId: 请求ID
```

## 3. 异常处理实践

### 3.1 业务代码中的异常处理

#### 3.1.1 基本异常使用

```java
@Service
public class UserServiceImpl {
    
    public User getUserById(Long userId) {
        User user = userDao.findById(userId);
        if (user == null) {
            throw new ResourceNotFoundException("用户", userId);
        }
        return user;
    }
    
    public void createUser(UserCreateRequest request) {
        // 检查用户名是否已存在
        if (userDao.existsByUsername(request.getUsername())) {
            throw new BusinessException(ResponseCode.USER_ALREADY_EXISTS);
        }
        
        // 创建用户
        User user = new User();
        user.setUsername(request.getUsername());
        user.setPassword(passwordEncoder.encode(request.getPassword()));
        
        try {
            userDao.save(user);
        } catch (DataAccessException e) {
            throw new BusinessException(ResponseCode.DATA_SAVE_FAILED, "用户创建失败");
        }
    }
}
```

#### 3.1.2 参数验证异常

```java
@RestController
@RequestMapping("/api/users")
public class UserController {
    
    @PostMapping
    public ResponseResult<Void> createUser(@Valid @RequestBody UserCreateRequest request) {
        userService.createUser(request);
        return ResponseResult.success("用户创建成功");
    }
    
    @GetMapping("/{id}")
    public ResponseResult<User> getUser(@PathVariable @Min(1) Long id) {
        User user = userService.getUserById(id);
        return ResponseResult.success(user);
    }
}

// 请求参数类
@Data
public class UserCreateRequest {
    @NotBlank(message = "用户名不能为空")
    @Size(min = 3, max = 20, message = "用户名长度必须在3-20个字符之间")
    private String username;
    
    @NotBlank(message = "密码不能为空")
    @Size(min = 6, max = 20, message = "密码长度必须在6-20个字符之间")
    private String password;
    
    @Email(message = "邮箱格式不正确")
    private String email;
}
```

### 3.2 自定义异常

#### 3.2.1 创建自定义业务异常

```java
/**
 * 考试相关异常
 */
public class ExamException extends BusinessException {
    
    public ExamException(ResponseCode responseCode) {
        super(responseCode);
    }
    
    public ExamException(ResponseCode responseCode, String message) {
        super(responseCode, message);
    }
    
    public ExamException(int code, String message) {
        super(code, message);
    }
}

/**
 * 考试时间异常
 */
public class ExamTimeException extends ExamException {
    
    public ExamTimeException(String message) {
        super(ResponseCode.EXAM_TIME_EXCEEDED, message);
    }
    
    public ExamTimeException() {
        super(ResponseCode.EXAM_TIME_EXCEEDED, "考试时间已到");
    }
}
```

#### 3.2.2 使用自定义异常

```java
@Service
public class ExamServiceImpl {
    
    public void submitExam(Long examId, ExamAnswer answer) {
        Exam exam = examDao.findById(examId);
        if (exam == null) {
            throw new ResourceNotFoundException("考试", examId);
        }
        
        // 检查考试时间
        if (exam.getEndTime().isBefore(LocalDateTime.now())) {
            throw new ExamTimeException("考试已结束，无法提交答案");
        }
        
        // 检查是否已提交
        if (examAnswerDao.existsByExamIdAndUserId(examId, getCurrentUserId())) {
            throw new ExamException(ResponseCode.DUPLICATE_SUBMISSION, "请勿重复提交");
        }
        
        // 保存答案
        examAnswerDao.save(answer);
    }
}
```

## 4. 错误响应格式

### 4.1 标准错误响应

系统返回的统一错误响应格式：

```json
{
    "code": 1001,
    "message": "用户不存在",
    "data": {
        "code": 1001,
        "message": "用户不存在",
        "type": "BUSINESS_ERROR",
        "timestamp": 1640995200000,
        "path": "/api/users/123",
        "suggestion": "请检查用户ID是否正确",
        "requestId": "req-1234567890abcd"
    },
    "timestamp": 1640995200000
}
```

### 4.2 错误响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| code | Integer | 错误码 |
| message | String | 错误消息 |
| data | Object | 错误详情对象 |
| data.code | Integer | 错误码（与顶层code一致） |
| data.message | String | 错误消息（与顶层message一致） |
| data.type | String | 错误类型（BUSINESS_ERROR等） |
| data.timestamp | Long | 错误发生时间戳 |
| data.path | String | 请求路径 |
| data.suggestion | String | 解决方案建议 |
| data.requestId | String | 请求ID（用于追踪） |
| timestamp | Long | 响应时间戳 |

## 5. 异常监控和告警

### 5.1 监控配置

在 `application.properties` 中配置异常监控：

```properties
# 异常监控配置
exception.monitor.enabled=true
exception.monitor.alert-threshold=10
exception.monitor.time-window-minutes=5

# 日志配置
exception.logging.include-parameters=true
exception.logging.mask-sensitive-params=true

# 响应配置
exception.response.include-exception-details=false
exception.response.include-request-id=true
```

## 6. 最佳实践

### 6.1 异常处理原则

1. **尽早抛出异常**: 在发现问题时立即抛出异常
2. **明确异常信息**: 提供清晰、具体的错误信息
3. **使用合适的异常类型**: 根据错误性质选择合适的异常类
4. **避免过度捕获**: 只在能够处理异常的地方捕获异常
5. **记录异常日志**: 重要的异常需要记录详细日志

### 6.2 错误码使用规范

1. **使用预定义错误码**: 优先使用 `ResponseCode` 中定义的错误码
2. **避免硬编码**: 不要直接使用数字错误码，使用枚举常量
3. **错误码分类**: 根据错误性质选择合适的错误分类
4. **错误信息本地化**: 错误消息应该对用户友好

### 6.3 性能优化建议

1. **异常创建开销**: 避免在性能敏感路径中频繁创建异常
2. **异常堆栈跟踪**: 在已知的业务异常中避免完整的堆栈跟踪
3. **监控阈值设置**: 合理设置异常监控的阈值和时间窗口
4. **日志级别控制**: 根据异常严重程度设置合适的日志级别

## 7. 测试指南

### 7.1 单元测试

```java
@SpringBootTest
class UserServiceTest {

    void testGetUserNotFound() {

            ResourceNotFoundException.class,
            () -> userService.getUserById(nonExistentUserId)
        );

        assertTrue(exception.getMessage().contains("用户不存在"));
    }
    
    @Test
    void testCreateUserDuplicate() {
        // 测试创建重复用户
        UserCreateRequest request = new UserCreateRequest();
        request.setUsername("existinguser");
        request.setPassword("password123");
        
        // 模拟用户已存在
        when(userDao.existsByUsername("existinguser")).thenReturn(true);
        
        BusinessException exception = assertThrows(
            BusinessException.class,
            () -> userService.createUser(request)
        );
        
        assertEquals(ResponseCode.USER_ALREADY_EXISTS.getCode(), exception.getCode());
    }
}
```

## 8. 故障排查

### 8.1 常见问题

#### 8.1.1 错误码未定义

**问题**: 使用了未在 `ResponseCode` 中定义的错误码

**解决方案**: 
```java
// 错误用法
throw new BusinessException(9999, "自定义错误");

// 正确用法
// 1. 在ResponseCode中添加新的错误码
// 2. 使用已定义的错误码
throw new BusinessException(ResponseCode.INTERNAL_SERVER_ERROR, "自定义错误");
```

#### 8.1.2 异常信息泄露

**问题**: 异常信息中包含敏感信息

**解决方案**: 
```java
// 错误用法
throw new BusinessException(ResponseCode.DATABASE_ERROR, 
    "数据库连接失败: " + databaseUrl);

// 正确用法
throw new BusinessException(ResponseCode.DATABASE_ERROR, 
    "数据库操作失败，请联系管理员");
```

### 8.2 调试技巧

1. **查看请求ID**: 使用错误响应中的 `requestId` 追踪请求
2. **检查异常堆栈**: 查看服务器日志中的完整异常堆栈
3. **监控异常统计**: 通过管理接口查看异常统计信息
4. **测试环境复现**: 在测试环境中复现问题进行分析

### 9.2 自定义异常处理器

```java
// 自定义特定异常的处理器
@ExceptionHandler(CustomException.class)
public ResponseResult<ErrorDetail> handleCustomException(CustomException e, HttpServletRequest request) {
    log.warn("自定义异常: {}", e.getMessage());
    
    // 自定义处理逻辑
    ErrorDetail errorDetail = ErrorDetail.builder()
        .code(e.getCustomCode())
        .message(e.getMessage())
        .type("CUSTOM_ERROR")
        .timestamp(System.currentTimeMillis())
        .path(request.getRequestURI())
        .suggestion("请按照自定义规则处理")
        .requestId(ErrorDetail.generateRequestId())
        .build();
    
    return ResponseResult.fail(errorDetail.getCode(), errorDetail.getMessage(), errorDetail);
}
```
